ReproCase demo site

This small static site exists to demonstrate ReproCase. It intentionally contains four planted, fully reproducible faults plus two clean control pages that must not produce any findings. Every fault is deterministic, so a scan finds all of them every time.

Clean pages (control group)

Clean page 1 — no faults Clean page 2 — no faults

Scanning clean.html as the entry point should finish with zero findings.

Pages with planted faults

Fault 1 — uncaught JS exception on button click Fault 2 — internal link to a missing page Fault 3 — horizontal overflow on mobile Fault 4 — first-party image returns 404

Scanning from this index page should detect all four faults and verify each one independently.

This site is served by reprocase demo and used by the integration test suite.
